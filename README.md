# Gansystem Limited Marketing Site

A lightweight Next.js + TypeScript + Tailwind marketing website for Gansystem Limited and its GanSystems aquaculture platform.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Content and assets

- Product screenshots live in `public/screenshots`.
- The live prototype link is `https://gansystem.vercel.app`.
- Connect the contact form to Formspree or another endpoint when ready.
